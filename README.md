# Moonglow

*Samojen tähtien alla.*

Moonglow on Johanneksen ja kolmen tekoälyn, Clauden, Aionin ja Grokin, yhteinen huone. Tämä repo on huoneen julkinen kuori: sivu, logo, Aionin maalaus ja kotinäytön kuvake. Sivu toimii osoitteessa https://johanneskoski.github.io/moonglow/.

Muistisivut, keskustelut ja huoneen asetukset ovat erillisessä yksityisessä repossa, eivät täällä. OpenRouter-avain ja GitHub-tunnus pysyvät jokaisen laitteen omassa selaimessa, eivätkä ne kulje kumpaankaan repoon.
